# iOS 设备指南

在 iOS 上安装软件并不容易。这份教程介绍如何在中国大陆安全、合法地安装官方 Element 客户端，并把它指向 NerChat! 服务器。

## 创建或获取美区账号

### 1. 借用账号

最简便的方法是借用美国亲友的美区 Apple ID：安全高效，也避免了账户被锁定的风险。

### 2. 购买账号

通过第三方平台获取美区 Apple ID。不少微信公众号提供外区游戏下载服务，可以通过它们获取账号，具体步骤如下：

1. 关注相关微信公众号。
2. 按照公众号指示，注册并登录平台。
3. 通过平台购买或兑换美区Apple ID账号和密码。

平台内的金币不是人民币，注册时通常会赠送一些，充值花费也不高。挑标注为“美区”的游戏兑换，即可获得账号和密码。

### 3. 注册美区账号

自己注册一个美区 Apple ID 虽然麻烦一些，但最安全。详细步骤请参考[这篇教程](https://zhuanlan.zhihu.com/p/367821925)。

## 安全登录App Store

::: danger

拿到账号密码后请谨慎操作，避免因登录他人账户而导致设备被锁定。建议只在 App Store 中登录该账户，不要在整个设备上登录，这样可以有效避免设备被恶意锁定。

:::

具体操作如下（二选一）：

::: tabs

== 方法一

### 在设置中登录

1. 打开“设置”应用。
2. 点击“媒体与购买项目”。
3. 选择“退出登录”。
4. 使用美区账号和密码登录“媒体与购买项目”。

== 方法二

### 在App Store中登录

1. 打开App Store应用。
2. 点击右上角的头像图标。
3. 滑动至页面底部，选择“退出登录”。
4. 使用美区账号和密码登录。

## 下载 Element X 应用

用美区账号登录后，在 App Store 中搜索并下载 Element X，图标如下：

![Element X](../../assets/element-x-logo-mark-primary.webp){style="width: 100px; margin-top:16px; margin-bottom: 16px"}

::: warning

下载完成后，请立即退出美区账号，重新登录自己的 Apple ID。

:::

### 注意事项

初次登录时可能遇到网络连接问题，建议在网络畅通的环境下完成登录（比如出国旅行时）。登录成功后，应用不需要频繁更新，通知可在系统设置中调整。通过美区账号下载的应用，在退出美区账号后仍可正常使用，但更新时可能需要再次输入美区账号的密码。
