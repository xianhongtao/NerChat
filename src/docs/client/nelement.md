# Nelement

![Nelement Icon](../../assets/nerchat/nelement_icon.png){style="max-height: 100px; margin-top:16px"}

## 软件概述

Nelement 是 Neboer 在 Apache 开源协议许可下，基于 Element Android 源码修改发布的开源 Matrix 客户端，适配 Android 系统，在中国大陆可以直接使用，默认连接 NerChat!。Neboer 会持续更新这个软件。

## 软件信息

- 软件名：Nelement
- 开发者：Neboer
- 包名：im.neboer.app
- 发布：Fdroid渠道
- 开源地址：[github.com/Neboer/Nelement](https://github.com/Neboer/Nelement)
