# 其他客户端

如果您不想使用 Neboer 修改过的客户端，完全可以用其他客户端连接 NerChat!。只是不少国外客户端下载比较麻烦，可以从 F-Droid 或 Google Play 两种渠道安装，连接问题需要您自行解决。

::: info

如果您有能力解决连接问题，我们欢迎并推荐您使用其他客户端，也希望您通过使用开源软件来支持开源软件的发展。

:::

## Element Android

第一次打开 Element 会比较麻烦：它默认连接 matrix.org，需要借助代理才能在国内正常使用。

打开后，操作与 Element 完全一致：点击“编辑”打开修改主服务器的窗口，添加新的主服务器 `https://chat.neboer.site`。

输入账号密码并点击登录，登录流程就完成了。

## iOS

关于 iOS，请参考[iOS 设备指南](ios-instructions)一章。
