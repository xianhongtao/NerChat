# 使用 Element X 连接 NerChat!

<!-- markdownlint-disable MD033 -->

1. 打开 Element X。

2. 选择 `手动登录`。

3. 选择 `更改账户提供方`。

4. 在服务器地址一栏填入 `chat.neboer.site`。

5. 点击 `继续`，按引导输入账号密码完成登录，即可连接到 NerChat!。
