# NerChat! 文档

欢迎阅读NerChat!的文档。

NerChat! 是一个开放、现代的即时聊天平台。这份文档会介绍平台的基本使用方法，带您快速上手。

在移动端可以点击上方的按钮展开左侧菜单，挑选感兴趣的章节阅读，也可以从头到尾通读一遍。每篇文章篇幅都不长，大致浏览一下就能对平台有相当完整的了解。

本网站支持夜间模式，点击右上角的功能按钮即可切换。

除非您早已非常熟悉 Synapse / Element，否则我们建议每一位 NerChat! 用户都完整地阅读 **所有文档**。它既是 NerChat! 的使用指南，也可以作为任何基于 Matrix / Element 的开源 IM 方案的入门读物；如果您也基于 Matrix / Element 开发了产品或平台，同样可以拿它作为帮助用户上手的材料。
