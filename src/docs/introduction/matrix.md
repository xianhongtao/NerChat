# 关于Matrix

![Matrix logo](../../assets/matrix-logo-white.svg){style="width: 100px; margin-top:16px; margin-bottom: 16px" class="only-shown-in-dark-theme"}

NerChat! 基于 Matrix 部署，所以在开始使用之前，有必要先了解一下 Matrix 是什么。

[Matrix](https://matrix.org/)（国内无法直接访问）是一个专注于加密即时通信（IM）的大型开源组织，旗下有多个生态的开源聊天服务端和客户端。

::: info

以下内容摘自 Matrix 官网

:::

Matrix 定义了一组用于去中心化通信的开放 API，适用于通过全球开放的服务器联盟安全地发布、保存和订阅数据，而无需单一控制点。用途包括即时消息 (IM)、IP 语音 (VoIP) 信令、物联网 (IoT) 通信以及连接现有的通信孤岛 - 为新的开放实时通信生态系统奠定基础。

简单说，Matrix 是一个自由的聊天网络，NerChat! 则是它在国内的一个小节点。受网络环境限制，NerChat! 目前还无法与 Matrix 联邦保持稳定连接，我们也期待它直通世界的那一天早日到来。
