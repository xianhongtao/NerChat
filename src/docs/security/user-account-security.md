# 用户账号安全性

NerChat! 不会对用户登录设置任何额外校验。

也就是说：任何知道您用户名和密码的人，都能登录您的账号。

有加密密钥兜底，盗号者也拿不到您的加密聊天记录，但他可以偷偷改掉您的密码、把您的设备踢下线，给您带来非常大的麻烦。

所以请妥善保管 NerChat! 的密码。虽然这个密码对管理员来说是透明的，但它仍然是保护您账号唯一的、也是最有效的屏障。

如果您对这种设计存在疑虑，也不必着急——在 Matrix 的世界里，真正值得信任的是设备上经过认证的密钥，而不是账号本身。您只需要认准绿色盾牌：看到它，就可以放心地认为房间里的聊天是安全的。这份安全感来自前面介绍的整套密码学机制，是现代密码学层面的强安全。

具体来说：您和对方的聊天内容，只会在你们双方各自的设备上正常显示，其他任何人——包括服务器的运行维护人员（也就是我们），也包括试图攻击服务器窃取聊天内容的黑客——都无法查看。这一点是能够保证的，因为服务器上只保存加密后的内容，不会留下任何明文。
