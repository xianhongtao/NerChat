# 本地备份

前面在“安全密钥”一章已经介绍过把密钥库备份到云端的方法：它非常方便，能让新设备很快拿到全部历史聊天记录。但密钥库毕竟存放在服务器上、不在自己手里，难免让人不太放心——即使我们承诺不会动用您的密钥，您依然可能担心服务器的所有者随时删除这份备份。为了尽可能保护自己的历史密钥，您完全可以把密钥库导出到本地，需要时再从本地恢复。

当然，服务器的所有者始终有能力删除您全部的加密历史聊天记录。如果您在意这些记录的价值，请把它们导出到本地。

::: warning

NerChat! 不承诺永久保留您的聊天记录，也不承诺永久保留您的账号——尽管我们会尽全力。因此请不要把 NerChat! 当作数据仓库或网盘使用。如果有些聊天记录您非常想留住，请把它们导出到本地。

:::

## 恢复密码库

“安全密钥”一章介绍了如何把 Megolm 密钥库加密后上传到服务器备份，本节介绍如何从服务器下载并恢复这个密钥库。

::: tabs

== Web

头像->隐私安全->安全备份->从备份恢复

![从备份恢复](../../assets/web/recover_from_backup.png)

== Mobile

设置->安全与隐私->恢复已加密消息->从备份恢复

:::

## 导出导入端到端房间密钥

除了上传到服务器，您也可以把密钥库导出保存在本地，方法如下：

::: tabs

== Web

头像->隐私安全->安全备份->导出房间的端到端加密密钥->输入并确认口令词组->保存

这里输入的口令词组只用于加密导出的密钥，导入密钥库时需要再次提供。

Web端和移动端的密钥库是通用的。

== Mobile

设置->安全与隐私->导出端到端房间密钥->选择导出位置->输入并确认口令词组->完成

这里输入的口令词组只用于加密导出的密钥，导入密钥库时需要再次提供。

Web端和移动端的密钥库是通用的。

:::

导入时选择“导入密钥”，再输入导出时设置的口令即可。
