# 安全与加密

NerChat! 基于 Matrix 部署，专注于让聊天内容安全、可信地传输。这里的“可信”，指的是您所使用的客户端完全开源：开源客户端的行为是透明的，经过开源组织和大量用户的长期审查，因此可以信任。NerChat! 发布的客户端只是在原客户端基础上做了少量修改，方便用户低门槛地上手和传播；这些修改同样开源，并遵守原软件的开源协议发布。欢迎各位审查 NerChat! 修改后的源代码，也欢迎针对它的安全性提出质疑。

安全的基础是加密，Matrix 的安全性来自一套复杂的加密系统。这套身份认证与消息加密机制，正是 Matrix 与其他聊天软件的重要区别。我们希望这些文档能让您了解 Matrix 的安全性，也看到开源开发者为此付出的努力。本章中有几篇内容非常关键，推荐所有人都读一读。

想了解 Matrix 加密的原理，可以参考[密码学综述](cryptology)；如果您对加密本身不感兴趣，至少也要读一读[安全密钥](secure-key)和[交叉认证](cross-sign)这两部分。

我们知道这是大多数用户最关心的部分，所以尽可能把 Matrix 保护聊天记录的做法讲清楚，让想要验证其安全性的用户了解这套协议的实现机制，从而更放心地使用。

如果您对加密完全不感兴趣，也完全可以只把 NerChat! 当成一个普通聊天平台来用（就像微信、QQ 一样），只需要记住一点：没有您的加密密钥，任何人都无法获取您的聊天记录——这里的“任何人”也包括我们，也就是服务器的运营方。如果您希望获得更全面、更彻底的保护，建议完整地阅读本章。
