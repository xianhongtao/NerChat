# 安全传输安全密钥

请不要用微*、Q* 之类的普通通信软件传输安全密钥：它们不提供端到端加密，数据会经过运营商的服务器，存在被读取、保存甚至泄露的风险。为了安全地传输密钥，请优先考虑以下方式：

::: info
这里没有贬低普通通讯软件的意思：上述软件各有优点，只是在传输安全性上不如端到端加密的通讯软件。
:::

1. **使用加密通讯工具**：选择支持端到端加密的通信工具，如 Si**al 或 Te****am，它们能确保密钥在传输过程中不被第三方截取或读取。

   ::: danger
   请注意：请使用当地合法的软件。
   :::

2. **物理传输**：最安全的方式仍然是物理传输——比如用 U 盘或移动硬盘拷贝密钥并亲自操作，可以完全避免网络攻击。

   ::: warning
   请不要把安全密钥存放在常用的存储介质上，详见[安全存储安全密钥](storage-secure-key)。
   :::

3. **本地传输**：如果需要无线传输（比如传到 iOS 设备上），请选用局域网内的传输工具。例如 [LocalSend](https://localsend.org) 虽然不带加密，但传输完全在局域网内完成，不经过任何第三方服务器——也就是说，安全密钥不会离开您的家庭或办公网络，被外部攻击的风险大大降低。

   ::: info
   NerChat! 维护团队与开源软件 LocalSend 没有任何关系；对 LocalSend 有疑问或想为它做贡献，请前往其社区 [LocalSend Community](https://localsend.org/zh-CN/community)。因使用该软件造成的任何直接或间接损失，NerChat! 不承担责任。
   :::

选好传输方式之后，还要用安全的方法保存密钥。有关密钥存储的详细建议，请参阅[安全存储安全密钥](storage-secure-key)。
