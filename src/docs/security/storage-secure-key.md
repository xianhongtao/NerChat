# 安全存储安全密钥

在导出安全密钥后，你将得到一个包含多个分段的密钥文件，通常格式如下：

```Encrypt Key
xxxx xxxx xxxx xxxx xxxx xxxx xxxx xxxx xxxx xxxx xxxx xxxx
```

**重要提示**：不建议把安全密钥直接存放在日常使用的设备上，比如个人电脑或安卓手机——这些设备存在被恶意软件扫描并读取密钥的风险，可能导致密钥泄露。详见[设备安全性](device-security)。

对于 **iOS 设备**，尽管其隐私保护相对严格、通常不易被攻击，仍要谨慎选择传输方式，避免因网络环境不安全而泄露密钥。详见[安全传输安全密钥](transfer-secure-key)。

## 推荐的安全密钥存储介质

1、**不常用的 U 盘**：把密钥存在不常用的 U 盘上，可以减少被他人借用或操作的机会。请避免使用常用 U 盘——它们会频繁接入其他电脑，被恶意软件感染的风险更高。

2、**用于冷备份的硬盘**：冷备份硬盘通常不联网、也不接入其他计算设备，能有效降低被攻击的风险。建议专门用于存放密钥等敏感数据，并定期做完整性检查。

3、**LTO 磁带**：LTO（Linear Tape-Open）磁带是目前最安全的长期存储介质之一，存储密度和耐用性都很高，可以在物理隔离的情况下保证数据安全。LTO 技术已发展到第 9 代（LTO-9），在合适的存储环境下，磁带寿命可达 30 年以上。它的单位成本也低，尤其在需要存储大量数据时，每 GB 成本远低于固态硬盘（SSD）和机械硬盘（HDD）。**LTO-4、LTO-5 的磁带机与磁带价格已经降到普通用户可以承受的水平**，是个人长期存储数据的经济选择。

- **LTO 磁带**：与固态硬盘（SSD）、机械硬盘（HDD）相比，LTO 磁带在存储容量、单位成本和长期保存能力上都有明显优势，适合长期归档和冷存储；而且它不依赖电源，离线状态下天然隔离了网络攻击的威胁。
   ::: info
   NerChat! 的维护团队并未实际使用过 LTO 存储，请根据自己的存储需求选择合适的介质；关于 LTO 磁带机和磁带的更多用法，可参考[知乎 - 个人如何玩转 LTO 磁带机](https://zhuanlan.zhihu.com/p/692565835)。
   :::

## 其他注意事项

1、**定期备份**：即使使用了上述介质，也要定期备份安全密钥，并把备份放在多个地点，避免单一介质损坏或丢失。

2、**加密存储**：建议在存放密钥的介质上再做一层加密，例如把密钥文件放进带密码的压缩包，双层加密能进一步提升安全性。

3、**物理安全**：把存储介质放在安全的物理环境中，例如保险箱等。

做好这些，可以显著提升安全密钥的存储安全性，降低被窃取或丢失的风险。
