# 设备安全性

NerChat! 提供自由、安全的聊天服务，但这并不等于每一位用户都必然拥有自由、安全的聊天体验。

世上没有绝对的安全，安全是相对的。Matrix / Element 提供的加密，改善的只是安全链中不受您控制的部分；而软件的绝大多数环节仍然运行在操作系统之上，操作系统又依赖设备本身。如果最底层的环境就不可信，那么在软件层面做再多加密也只能是自欺欺人——连设备和操作系统的安全都无法保证，隐私安全便无从谈起。

:::danger

我们非常强烈地建议 NerChat! 的所有用户重视自己的隐私安全。

:::

## 为什么要重视隐私安全

无论出于什么想法使用 NerChat!，您至少是在意自己的隐私和安全的。Matrix 的强加密，加上开源方案天生不够“讨好”用户，让 NerChat! 相比许多现成的 IM 并不算好用。既然牺牲了这么多易用性，换来的是什么？正是 Matrix 协议带来的隐私和安全。既然已经用上了 NerChat!，不妨再纯粹一点，看看这个干净、不被打扰的开源世界能为生活带来什么改变……

## 挑选合适的硬件

一般来说，电脑比手机更安全。国产手机泄露用户隐私的新闻早已不新鲜，我们希望有条件的用户尽量不要在国内品牌或国产移动设备上使用 NerChat!。这只是一个建议——您不必为此专门换掉手里的华为 / 小米 / OPPO 手机，但请了解：在这些手机上使用 NerChat! 时，它所承诺的隐私和安全是得不到保证的。国产厂商常把“系统安全稳定”当作卖点，但在监管尚不完善的国内市场，这些说法更多只是噱头，用户权益难以充分保障。相比之下，美国和欧盟的法律更严格，要求企业处理用户数据时遵守严格的隐私规定，在一定程度上提高了数据安全的保障。iPhone 因较严格的隐私政策而受欢迎，苹果也致力于避免用户数据被滥用或泄露，所以如果不知道该买什么，苹果手机是比较推荐的选择。

## 操作系统的安全性

一般来说，新版本系统比旧版本更安全、更好用，自由开源的系统也比封闭系统更值得信赖。因此在这一层面：Linux 发行版比 Windows 和 iOS 更安全，自由的 Android 系统比 iOS 安全，而 iOS 又比各厂商定制的系统安全。这只是一种粗略而主观的排序，但足以说明问题。

:::danger

我们 **非常强烈地** 建议用户不要在任何国产操作系统上使用 NerChat!。

:::

不过无论用的是什么品牌的手机，使用软件时都应格外小心，确认应用不会在未经允许的情况下收集或传输个人数据。有条件的用户可以考虑把系统刷成开源系统（例如 LineageOS 等）：这类系统通常更透明，社区审核也更严格，被植入恶意代码的风险更小。刷机需要一定的技术能力，这里只是建议愿意动手的用户尝试。在 iOS 上，苹果默认会收集部分数据用于广告跟踪，您可以选择性地关闭这些功能以提高安全性。

## 使用自由软件

自由软件最大的优势之一是透明：源代码公开，任何人都可以查看、审计和改进，这有助于发现并修复漏洞，提升安全性和可靠性。在智能手机上，操作系统和应用要处理大量个人数据与敏感信息，使用自由软件可以降低恶意后门和隐私泄露的风险。

举个例子：您或许觉得 NerChat! 很安全，但别忘了——您使用的国产输入法可能正在把您输入的“加密”消息上传到自己的云词库，用于联想比对，顺便拼出更完整的用户画像，这样一来，我们实现的加密也就失去了意义。改用 Trime 这类开源输入法，可以在不影响中文输入体验的前提下更安心地打字，让聊天真正保持私密。另外，有些手机会把收到的通知内容回传到自己的服务器：每当您的 Matrix 客户端收到新消息、解密并显示在通知栏后，通知内容都可能被上传用于“体验改进”，同样会损害消息的隐私性。使用开源的手机系统框架就不会有这个问题。

## 形成安全的使用习惯

设备和操作系统安全之后，最后要保证自己的软件和使用习惯也是安全的：定期查杀病毒、定期更新系统和软件、不要使用口碑过差的软件。例如某些国内大厂的软件会扫描用户硬盘内容，可以考虑用工具限制其行为，或者干脆不用。

:::danger

我们 **非常强烈地** 建议用户留意自己日常所用软件的口碑。

:::

做到以上几点，您就可以在使用 NerChat! 时把设备和隐私的安全水平提高一截，更好地保护自己的数字生活。
