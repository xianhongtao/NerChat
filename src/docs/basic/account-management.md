# 账号管理

NerChat! 用起来很直观：打开网站或安装客户端，注册账号就可以使用。之后在同一台设备上再次打开，软件会自动登录，体验和微信、QQ 这类国产软件没有区别。

当然，请妥善保管账号密码，防止他人登录您的账号。要注意的是，与普通聊天软件不同，这里的“他人”也包括服务器的维护者。

::: danger

## 关于登录密码的安全性

Matrix 虽然使用复杂的机制保护客户端的数据，但您的登录密码是明文发送给服务器的；密码虽然加密存储，服务器的所有者拿到它依然很容易。请小心——您的密码并不只有您自己知道。

所以设置密码时至少要遵守以下三点：

1. 请不要设置任何您常用的密码，否则可能增加您其他账号被盗取的风险。
2. 请确保密码只保存在可信的登录设备上，就像微信QQ提供的保护一样。
3. 请不要使用相同的登录密码和安全短语！如果您这么做了，那么您就相当于授权了服务器的所有者访问您的所有历史聊天记录，并且以受信任的方式登录您的账号！

**重复一遍，不要使用相同的登录密码和安全短语！**

如果您仍然担心明文密码会被服务器所有者用来顶替登录，请参考[威胁模型](../security/device-and-secret#威胁模型)。

:::
