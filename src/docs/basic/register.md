# 用户注册

下载任意版本的客户端，或者打开网页版，就可以注册成为 NerChat! 的一员。

NerChat! 目前处于**开放注册**状态，任何人都可以注册任意数量的账号。不过为了节省服务器资源，我们建议您只注册一个账号：这一个账号就代表您在 NerChat! 上的身份，可以在多个平台登录。

根据不同的客户端，注册流程也会不同。

::: warning

注册时需要填写“用户名”。这个用户名**仅用作账号 ID**，因此必须符合规范：不能全是数字或符号，不能含大写字母，也不能出现非标准字符（例如中文）。

登录之后您可以修改显示昵称，但必须先给自己选一个合法的 ID；ID 也不能与已有的 ID 重复，否则无法注册。

不用担心，输入时 NerChat! 会实时检查名字是否可用。

:::

::: danger

NerChat! 对密码有严格要求：弱密码会让账号轻易被他人登录，NerChat! 会**拒绝**这类密码。请为自己设置一个强密码。

:::

::: tabs

== Web

1. 打开 NerChat! 官方网站 **chat.neboer.site**，等待页面加载完成，然后点击“创建账户”。

![创建账户](../../assets/register_page.png)

2. 在窗口中输入想注册的用户名和密码，注意符合上面的要求；密码需要输入两遍以确认。

3. 注册流程完成后，会自动进行首次登录。

== Mobile

对于安卓手机，推荐您使用NerChat!推荐的客户端[Nelement](../client/nelement)。如果您希望使用其他兼容Matrix协议的客户端如Element，请参考[第三方客户端登录指南](../client/other-clients)。

1. 安装并打开客户端，稍等片刻进入功能介绍页面，新用户请选择“创建账户”。

2. 跳过官方的统计问卷。跳过之后 App 会进入加载状态，等待时间取决于您的网络情况。注意：如果您使用的是 Element Android 等非 NerChat! 官方客户端，还需要额外几步。

3. 在弹出的“请输入用户名和密码”窗口中填写用户名和密码，然后点击“下一个”。

4. 注册完成后会弹出“恭喜，您的用户已创建”提示。您可以选择“个性化”来编辑头像、昵称等信息，也可以选择“带我回家”直接进入软件主页。

5. 在“帮助改进 Nelement”界面中选择“不是现在”，因为大陆用户无法把统计信息直接发送给 Element 官方。

:::

注册成功后会自动完成首次登录。首次登录后需要做些什么，请参考[用户登录](login)。
