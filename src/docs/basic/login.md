# 用户登录

登录之后，还需要先完成一些设置，确保加密等各项功能可靠运行，然后才能安心开始聊天。

::: info

NerChat! 和传统聊天平台不同：您的消息由自己的密钥严格加密，因此在 Matrix 上通常需要多一些步骤。

有关加密的更多信息，请参见[安全](../security/security-and-encryption)。

:::

## 首次登录

首次登录后，请先生成自己的安全密钥并导出，再把它发送到您的手机或电脑上。

具体的操作请参考[生成并导出安全密钥](../security/secure-key#生成并导出安全密钥)。

导出安全密钥后，最好立刻把它发送给自己的其他设备作为备份，或者牢牢记住自己的安全口令。密码忘记、密钥丢失，聊天记录就再也无法解密了。

## 新设备登录

如果您已经在某台设备上登录并导出过密钥，那么换新设备登录时，软件会主动向您索要这份密钥。

任何形式的新登录都属于新设备登录：换了一个新的登录环境，或者用清空了数据的浏览器、客户端登录 NerChat!，都会被当作一台新设备。

在新设备上登录请参考[加载安全密钥](../security/secure-key#加载安全密钥)。

## 登录之后

登录后，您的聊天列表里会自动出现一个群聊——“Nelement 尼尔人”。

这是我们服务器的官方交流群，新用户注册后会自动加入。来和我们打个招呼吧！

## 搜索群聊、搜索用户

如果您想和某个人开始聊天，可以这样操作：

::: tabs

== Web

点击 + 号“开始新的聊天” -> 在对话框中输入对方的 ID，如 *@tester:chat.neboer.site* -> 在搜索结果中点击对方头像，添加对方为好友。

然后给对方发送第一条消息，两人的对话就开始了。

== Mobile

在对话列表页面点击右下角的绿色“编辑”按钮，选择“开始聊天”，然后在搜索框中输入对方的 ID，如 *@tester:chat.neboer.site* ，在搜索结果中点击对方头像，发送一条消息即可开始聊天。

:::

搜索并加入公开群组的方法类似，只需点击“加入公共房间”按钮来查找房间。

## 其他操作

您可以自由创建房间，也可以逛逛别人建的公开房间。建议把私密的小房间设为加密；公开房间则没有必要加密，因为任何人都能看到。
